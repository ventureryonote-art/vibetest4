# ここから下は Claude Code が埋めた仮説

## 3行の質について（1つだけ指摘します）

2行目が非常に強いです（「1日10人前後」「探すのに15分」と、件数と時間が入っている）。
**弱いのは1行目です。** 「斉藤内科の院長」までは下りていますが、**お名前**と、
**同じように会える医院がもう2つ**あるかが書かれていません。1軒だけだと、
そこで通じた話が他でも通じるのかが分からず、2軒目で作り直しになります。
今回はこちらで仮に置いて進めます（🔮 が付きます）。

## 今回作るものの範囲（絞りました）

**「検査結果が返ってきた患者さんへの、電話連絡の待ちリスト」だけに絞ります。**
検査会社システムや電子カルテとの自動連携、患者さん側からの入力は今回作りません
（外部システムとの接続と患者側の画面は第2〜3回で扱うため、
今回は**院内で院長・スタッフが自分で登録して自分で消し込む部分**だけにします）。

扱うデータは1種類（**検査結果の連絡待ち1件**）、項目は5つまで、
操作は「登録する・探す・状態を変える」の3つだけです。

---

## 解く課題

🔮 **今その人はどうやっているか**: 検査会社から届いた結果の紙（またはFAX／専用サイトの印刷）を
受付のトレーに積み、院長が診療の合間に上から見て電話。
かけた分には紙にレ点、不在だった分は付箋を貼って翌日に回している、と思われる。
紙は診察室・受付・カルテの間を移動するため、**「今どこにあるか」が人の記憶に依存している**可能性が高い。
　→ 確かめ方: 「結果が届いたあと、電話するまでに紙はどこを通りますか？　かけ終わった紙はどうしていますか？」

🔮 **かかっている時間 / 費用**: 探すのに1日15分（ここは事実）。
これが週5日で **週1.25時間、月およそ5時間**。
加えて、不在で1回でかけ直しになる患者さんが1日10人中2〜3人いるとすると、
その**かけ直し自体の管理**にも同じくらいの時間がかかっていると思われる。
かけ忘れは月2〜3件程度で、翌週の外来で気づいて謝る形になっている可能性が高い。
金額よりも、**院長の診療の合間の15分**という一番高い時間が消えているのが痛い。
　→ 確かめ方: 「1日10人のうち、1回で電話がつながるのは何人くらいですか？　かけ忘れは月に何件ありますか？」

🔮 **本当に困っているのは「探す時間」ではなく「かけ忘れ」**の可能性が高い。
15分は我慢できるが、かけ忘れは患者さんとの信頼に直結し、内容によっては受診の遅れになる。
　→ 確かめ方: 「15分の手間と、かけ忘れと、なくしたいのはどちらが先ですか？」

## なぜ今まで誰も作らなかったのか

🔮 **市場が小さい**（5類型のうち「市場が小さい」）。
無床クリニック1軒が管理系の道具に出せるのは月3,000〜10,000円程度と思われ、
医療系システム会社は電子カルテ（初期100万円〜）とセットでしか売らないため、
**「結果連絡の待ちリスト」だけを単体で作る採算が合わなかった**可能性が高い。
電子カルテ側にも似た機能はあるが、**院長が電話するときの手元では使われていない**と思われる。
　→ 確かめ方: 「今お使いの電子カルテに、結果を連絡したかどうかを記録する場所はありますか？　使っていますか？」

## 出口の3点

### 🔮 ① 誰が払うか

払う人は**院長本人**（無床クリニックは院長＝経営者で、決裁が1人で終わる可能性が高い）。
ただし**使う人は受付・看護師スタッフ**になる可能性があり、
「院長が買って、スタッフが使う」ずれが起きやすい。
医院はレセコン・電子カルテの保守に月2〜5万円を払う商習慣があるため、
**月数千円の道具に払う下地はある**と思われる。
一方で「新しい道具を1つ増やす」こと自体への抵抗（スタッフ教育・入力の二重化）のほうが障壁になりそうです。
　→ 確かめ方: 「実際に電話をかけるのは先生ご自身ですか、スタッフの方ですか？　電子カルテの保守には月いくら払っていますか？」

### 🔮 ② どう届くか　← **最優先で確かめること**

**下の経路**（紹介・口コミ・業界内の直接接触）で動いている市場と思われます。
具体的には、地区医師会の集まり、製薬会社のMR、医療機器・検査会社の営業担当、
そして**院長同士の「あれ使ってる？」という会話**。
「クリニック 検査結果 連絡 管理」で検索する院長はほぼいない（課題を言語化していないため）。

**あなたの入り口は「家族がずっとかかっている患者」という関係**です。これは強い接点ですが、
**患者としての信頼が、仕事の発注につながるとは限りません。**ここが今回いちばんの不確実性です。
　→ 確かめ方: 「先生は、新しい道具ってどこで知ることが多いですか？　近くの先生同士で情報交換されますか？」

### 🔮 ③ 受け取れるか（決済・審査・規制）

- **確認したか**: いいえ（未確認）
- 🔮 医院に**業務用の道具として売る**形（B2B・院内の管理ツール）であれば、
  決済代行の禁止業種にはあたらない可能性が高いです。効能をうたう健康商品ではないためです。
  ただし**「医療・健康」は要審査業種として扱われることがある**ので、申込み時に説明が要ります。
  　→ 確かめ方: 決済代行（Stripe等）の禁止・制限業種一覧を読む。これはコードを書かずに30分で確定します。
- ⚠ **こちらのほうが重い問題です。** 検査結果は**要配慮個人情報**にあたります。
  今回作るツールは**ブラウザの中（localStorage）にだけ保存**し、サーバーに送りません。
  そのうえで、**画面に入れるのは患者番号かイニシャルまで**とし、
  氏名・検査値そのものは入れない形にします。（今回の実装ではここを守ります）
  　→ 確かめ方: 「患者番号だけで、どの方か分かりますか？　それとも名字がないと厳しいですか？」

## 競合

🔮 **既存の競合**:
- 電子カルテの付随機能（あるが、電話する場面で開かれていない可能性が高い）
- 紙のトレー＋付箋（無料・今の方法。**これが本命の競合**）
- 汎用のタスク管理アプリ（患者情報を入れる先として院長が心理的に選びにくい）

**DIY競合**: 院長がスタッフにExcelで表を作らせる／自分でChatGPTに作らせる。
→ 表は作れますが、**診療の合間に開いて、片手で1タップ状態を変える**ところまでは続きません。
実際、そこで止まって紙に戻るのが一番多いパターンだと思われます。

🔮 **選ばれる理由**: **埋め込み。**
「結果が届いた順に並ぶ・かけたら消える・不在は明日に戻る」という、
**院長が午前の診療の合間にやっている動作そのもの**を画面にします。
一度これで回り始めると、抜くと「誰にかけたか分からない」状態に戻るので外せなくなります。
機能の数では勝てません（電子カルテのほうが多機能です）。勝てるのは**この15分の中に入っていること**だけです。
　→ 確かめ方: 「電話をかけるのは、1日のどのタイミングですか？　そのとき手元には何がありますか？」

## 🔮 やらないこと（3つ）

- **検査会社・電子カルテとの自動連携をしない** — つなぐ話が始まると数か月かかる。まず手入力で成立させる
- **患者さん側の画面・通知を作らない** — 患者さんに新しいアプリを入れさせない。連絡は今まで通り電話
- **検査値そのものを保存しない** — 「異常あり／なし」までにとどめる。要配慮個人情報を持ち込まない
